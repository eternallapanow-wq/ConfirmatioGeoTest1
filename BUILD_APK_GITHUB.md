# Budowa gotowego APK bez Android Studio

Projekt zawiera workflow GitHub Actions: `.github/workflows/build-apk.yml`.
Po umieszczeniu projektu w repozytorium GitHub, workflow buduje aplikację automatycznie.

Gotowy artefakt nazywa się `ConfirmatioGeoTest-APK` i zawiera plik `ConfirmatioGeoTest.apk`.

Po pobraniu APK na Androidzie trzeba zezwolić przeglądarce / menedżerowi plików na instalowanie aplikacji z tego źródła.
